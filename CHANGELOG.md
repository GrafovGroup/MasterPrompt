# Changelog

## 3.1 — November 8, 2026

Incorporates practical lessons from improving [Waving.ca](https://waving.ca) into the existing universal workflow. This release records implementation and verification lessons, not measured ranking or conversion gains.

| Lesson | Change in the master prompt |
| --- | --- |
| Logo and button exploration need distinct purposes and a durable selection | Sections 2 and 6 clarify selection authorization, focused alternatives, compact usable controls and consistent application of the chosen variant. |
| Existing ranges can be presented clearly without invented models, prices or rental terms | Sections 8 and 10 strengthen catalogue/package distinctions, buying-guide links and context-aware quote intake. |
| A bilingual journey includes state and interactions, not just translated prose | Sections 6, 8 and 12 cover French filters/labels, request changes, language switching, narrow navigation and unobstructed controls. |
| Owner-supplied video needs preparation and real playback checks | Section 7 adds inspection, web derivatives, posters, meaningful audio/accessibility, provenance and live interaction checks. |
| Later sessions need an accurate current state | Sections 16–18 strengthen approved-design records, source/deployed revision evidence, proportionate checks and project handoff. |
| Sitemap submission, URL acceptance and indexing can have different outcomes | Section 18 adds per-engine receipts, live versus dashboard counts, bounded retries and explicit error reporting. |

Preserves the five-competitor research-to-implementation cycle, factual integrity, business-specific modules and existing project overrides. No Waving-specific branding, inventory, prices, service claims or private account details become universal defaults.

Prompt-maintenance guidance was checked against [OpenAI's guidance on focused prompts and repository instructions](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra). The update narrows document-reading and QA requirements for small edits instead of making every request repeat a full launch.

## 3.0 — November 8, 2026

- Added the five-site competitive research and implementation cycle: establish our baseline, collect dated search evidence, inspect relevant journeys, prioritize opportunities, implement authorized improvements and verify the result.
- Distinguished improvements to confirmed offerings from unconfirmed new business capabilities.
- Established `MASTER_PROMPT.md` in this repository as the canonical prompt and documented its use in the README.
