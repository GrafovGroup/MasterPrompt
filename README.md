# Grafov Group Universal Master Prompt

The canonical version of the reusable website launch and improvement prompt is [MASTER_PROMPT.md](MASTER_PROMPT.md).

Current version: **3.1**, updated November 8, 2026. See [CHANGELOG.md](CHANGELOG.md) for the changes and their practical basis.

## Use the prompt

1. Open `MASTER_PROMPT.md` and copy or download the complete document.
2. Fill in the project inputs for the specific website, keeping private project information in that project's authorized workspace rather than this public repository.
3. Provide the completed prompt to the coding agent with the relevant repository, approved assets and business facts.

Existing approved brand decisions and the current project's explicit instructions take precedence over universal defaults. Choose the appropriate execution mode for a new build, an existing brand, a resumed project, a focused edit or strategy-only work. A focused edit uses the relevant requirements; it does not restart the entire launch process.

## What's new in version 3.1

Lessons from improving Waving.ca are integrated into the relevant sections:

- Compare requested design alternatives in context, preserve the exact selected variant, and keep compact controls distinct from the logo and easy to use.
- Make confirmed product ranges, comparable rental packages and useful buying guides lead into correctly prefilled enquiries.
- Preserve appropriate selections through request-type and language changes; check French labels, narrow mobile navigation and sticky controls.
- Prepare owner-supplied video for the web, preserve meaningful audio and provenance, and verify actual playback on the live host.
- Keep current project records and source/deployment evidence aligned; scale testing to the change.
- Record Google and Bing submissions separately, including acceptance, processing, errors and observed indexing.

These are reusable workflow lessons. Waving's visual identity, specific inventory, package terms and footage are not defaults for other brands.

## Existing research-to-implementation cycle

Version 3.1 retains the five-competitor cycle introduced in version 3.0:

- Research five relevant high-ranking competitors using current, query-specific Google and Bing evidence where available.
- Compare SEO, AEO, desktop/mobile UX, conversion journeys, products, services and trust evidence against the actual existing site.
- Turn useful findings into prioritized implementation tasks and acceptance checks.
- Keep proposed new business capabilities separate until delivery capability and terms are confirmed.
- Implement authorized improvements in English and French, verify the affected journeys, and report actual release and measurement status.

The prompt also retains the established branding, factual integrity, bilingual content, enquiry delivery, accessibility, search, source control and release requirements.

## Maintaining the source

Make future universal changes in `MASTER_PROMPT.md` in this repository. Update the version, date, README and changelog when the prompt changes materially. Integrate lessons where they apply and remove superseded or redundant instructions. Keep the full prompt self-contained; the changelog explains revisions but is not required to execute it. Git history preserves previous revisions; avoid separate competing copies of the current prompt.
